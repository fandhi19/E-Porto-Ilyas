ANALISIS MATERI
Konteks & Tujuan Context & Objectives

Materi ini dirancang untuk peserta didik Fase E (Kelas X) SMAN 4 Yogyakarta dengan fokus pada dasar algoritma dan pseudocode sebagai fondasi berpikir komputasional.

Tujuan pembelajaran: murid mampu menganalisis permasalahan sederhana, menyusun langkah penyelesaian dalam bentuk flowchart maupun pseudocode, serta mengomunikasikan logika program secara terstruktur.

Kelebihan & Kekurangan Strengths & Weaknesses

Kelebihan: materi disusun berjenjang dari konsep konkret ke abstrak; penggunaan analogi kehidupan sehari-hari mempermudah pemahaman; visual slide menarik dan interaktif.

Kekurangan: sebagian murid mengalami kesulitan abstraksi logika pada tahap awal; penyampaian konsep iterasi (loop) memerlukan waktu ekstra; ketergantungan pada visual dapat mengurangi latihan mandiri.

Kajian Teori Theoretical Framework

Penyusunan materi mengacu pada Teori Perkembangan Kognitif Piaget — peserta didik Fase E berada pada tahap operasional formal, sehingga mampu berpikir abstrak dan hipotetis.

Pendekatan Teaching at the Right Level (TaRL) diterapkan dengan menyediakan variasi tingkat kesulitan soal, memastikan setiap murid belajar sesuai kesiapannya. Diperkuat Scaffolding Vygotsky melalui bimbingan bertahap sebelum praktik mandiri.

Konteks & Tujuan Context & Objectives

Materi Dasar Pemrograman C++ diperuntukkan bagi murid Fase E yang telah menguasai konsep algoritma. Fokus pada sintaks dasar, variabel, tipe data, dan I/O.

Tujuan: murid mampu menulis program C++ sederhana, memahami alur eksekusi, dan mendebug error dasar secara mandiri.

Kelebihan & Kekurangan Strengths & Weaknesses

Kelebihan: C++ relevan dengan industri; syntax jelas dan terstruktur; hasil program langsung terlihat (output terminal).

Kekurangan: kurva belajar compiler setup cukup tinggi; error handling membingungkan pemula; waktu praktikum sering kurang untuk debugging.

Kajian Teori Theoretical Framework

Menggunakan pendekatan Constructionism (Papert) — murid belajar dengan membangun artefak nyata berupa program yang berjalan.

Didukung Pair Programming untuk kolaborasi dan Cognitive Apprenticeship melalui demonstrasi bertahap dari guru.

SIKLUS 3 Struktur Kontrol — Percabangan & Perulangan

Konteks & Tujuan Context & Objectives

Materi Struktur Kontrol (if-else, switch-case, for, while, do-while) sebagai lanjutan logika pemrograman dasar yang telah dikuasai pada Siklus 2.

Tujuan: murid mampu merancang alur kendali program untuk menyelesaikan studi kasus nyata, serta memilih struktur kontrol yang paling efisien.

Kelebihan & Kekurangan Strengths & Weaknesses

Kelebihan: materi sangat aplikatif dengan banyak kasus nyata (kalkulator, validasi input); visualisasi flowchart mempermudah pemahaman logika.

Kekurangan: potensi infinite loop pada murid pemula; perbedaan kognitif cukup terasa — sebagian murid butuh pengulangan konsep lebih banyak.

Kajian Teori Theoretical Framework

Berbasis Problem-Based Learning (PBL) — murid menyelesaikan masalah kontekstual sehingga pemahaman struktur kontrol tumbuh dari kebutuhan nyata.

Menggunakan Trace Table Strategy untuk melatih penalaran algoritmik dan Peer Feedback untuk memperkuat kolaborasi.

SIKLUS 4 Pengolahan Data dengan Microsoft Excel

ONLINE
[ DOWNLOAD_PDF ] [ BUKA_DI_TAB_BARU ]
Konteks & Tujuan Context & Objectives

Materi Pengolahan Data Excel disusun untuk membekali murid keterampilan analisis data spreadsheet — mulai dari formula dasar, fungsi logika, hingga visualisasi grafik.

Tujuan: murid mampu mengolah dataset sederhana, menyusun laporan berbasis formula, serta menarik kesimpulan dari data secara sistematis.

Kelebihan & Kekurangan Strengths & Weaknesses

Kelebihan: keterampilan Excel sangat dibutuhkan dunia kerja; pembelajaran langsung hands-on; hasil olahan data dapat langsung direfleksikan secara visual.

Kekurangan: variasi versi Excel antar perangkat membingungkan; murid dengan kemampuan low-end device terkendala performa; waktu terbatas untuk latihan rumus kompleks.

Kajian Teori Theoretical Framework

Menerapkan Experiential Learning (Kolb) — murid mengalami langsung siklus do → reflect → think → apply saat mengolah dataset nyata.

Diperkuat kerangka Data Literacy Framework untuk membangun kemampuan berpikir berbasis data, serta Authentic Assessment melalui proyek laporan berbasis spreadsheet.
